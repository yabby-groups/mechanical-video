# 打印机第二批拆解计划：EP07–EP09

更新：2026-11-02。用户已接受EP06当前0092交付版，并明确要求EP07～EP09“拆解机器，不能跑题，而且风格要一致”。本批以真实打印机总成的连续拆解/回装为内容主体。EP06用户交付收口，原QA记录与评分不追改。

## 唯一方向

**继续拆同一台打印机，每集拆一个尚未讲透的总成，看清真实零件、连接和配合，再装回去。** 原理跟随眼前机构简短解释。撤回此前振纹、拉丝、压力等故障/原理专题方向，不把正文做成曲线、截面幻灯片或参数教程。本批是当前新增计划，不恢复旧十二集或历史同号队列。

## 三集安排

| 集数 | 拆解对象 | 标题候选 | 观众看到的主要拆解动作 | 新增内容 |
| --- | --- | --- | --- | --- |
| EP07 | XY皮带张紧总成 | 这颗螺丝，怎样把整条皮带拉紧？ | 整机定位张紧端，连续移出总成，分开外壳、移动件、轮组与调节件，再回装并展示有限调节动作 | EP03讲两路皮带怎样配合；本集看张紧端内部怎样固定、导向和调节 |
| EP08 | X轴滑架与直线导轨总成 | 喷头拆下来，谁让它只能沿直线走？ | 保持横梁参照，将工具头与滑架按实际连接关系教学展开，露出连接件、滑块和导轨，再逐级回装、有限往返 | EP02讲机架承力；本集看工具头到滑架、滑块、导轨、横梁的连接层次，以及传力与导向的区别 |
| EP09 | 挤出机传动与压紧总成 | 机头里这套齿轮，怎样夹住一根塑料丝？ | 从整机追到工具头，分开可见外壳与固定件，展开电机、传动件、送料轮和压紧机构，回装后沿真实传动链动作 | EP01已有基础送料，本集只深入尚未展示的内部传动与压紧结构；不重复线材走向、软化和喷嘴成形 |

顺序为07→08→09：从XY传动一端拆起，沿横梁走到滑架，再进入工具头。三集始终有同一台机器和相邻总成作为方向参照，不做互不相关的零件拼盘。

标题中的螺丝、传动级和零件名称均须以选定源分支核实。当前是选题规划，不宣称这些内部件已逐一验证。若现有张紧器并非所述调节结构，按实际总成改标题和动作，不强造零件兑现标题。

## 每集的连续内容安排

**EP07：张紧总成**

整机有限XY运动辨认对象 → 沿现有皮带找到实际张紧端 → 将局部总成教学移出但保留安装位置参照 → 分开真实连接件、支撑件和轮组 → 在源证据支持下展示调节件与移动件的配合 → 回装到同一位置，结束于“调节的不是螺丝本身，而是轮组/带路的状态”（具体关系核实后定稿）。不展示无实测依据的甩带、跳齿、错层故障，不讲通用张力数值。

**EP08：滑架与导轨**

工具头沿X轴运动 → 保留横梁，教学展开工具头与滑架连接 → 依次露出固定件、滑块、导轨及其与横梁的连接 → 有限动作区别“皮带拉着走”与“导轨约束方向” → 按连接关系回装 → 同一方向再走一次兑现机构配合。没有可靠内部源件时，不剖开滑块编造滚珠循环；不把滑块滑出导轨当作真实维修操作。

**EP09：挤出机内部**

工具头在整机中的位置明确 → 沿实际外壳和固定关系教学展开 → 展示电机到送料轮的真实传动链 → 展开压紧机构，看它怎样接近线材 → 回装并进行源支持的有限送料动作 → 结尾回扣“传动负责转动，压紧配合送料”。传动级数、齿数、齿轮方向、单双驱及弹簧存在与否都先查选定分支，不能从另一款挤出机拼接。线材仅作明确示意，不宣称接触力仿真。

上述是内容顺序，不是最终时间线，也不是实际装配/维修步骤。正式片目标90–105秒；源结构或新增信息不足则调整拆解范围，不用慢动作、循环或重复旁白填时长。

## 风格锁定

- 同一台Voron打印机、既有橙色机架、灰青工具头、深色舞台、材料、灯光和相机语言。优先复用EP03成熟连续运动方法及相关EP04/05/06实际场景与CAD缓存；开工前记录选定版本路径及哈希，并实际对照基线帧/片段。
- 从整机进入局部，真实零件沿易读路径展开，保留朝向和安装位置，再连续回装。保留教学展开标识；动作不冒充真实拆卸顺序。不能凭镜头掩盖错误连接或穿模。
- 每集一个主总成、一个可复述关系，不把机器换成独立悬空图解。局部近景保留相邻结构参照，标签只负责辨认零件。
- 旁白继续qwen3-tts-flash / Kai，自然语速；字幕继续既有单行位置，每条≤20字符；合成机械声围绕可见动作，不堆冲击音。保留已批准历史音频。
- 复用现有原生输出与编码链，分别记录规格；正式片≥90秒、竖屏1080×1920编码、30fps、H.264/AAC。每集独立新指纹，不修改历史归档或跨版本拼帧。

## EP07先行的制作准备

1. 核对当前XY张紧端源分支、实例映射、独立导出和实际连接；列清固定件、可动件、轴/轮、调节件及可复用缓存。不要预先冻结“转螺丝带动哪件”的文案。
2. 核对EP03已有画面与EP01已讲内容，特别记录三集新增拆解信息；EP09若内部传动已完整讲过，先重新收敛同一总成中未讲透的机构，不再生产重复送料课。
3. 选定基线场景、输出与哈希，制作开场/总成展开/回装的最小实际证明；联查附件、完整路径净空、邻段、字幕/标签、拟音时点。新生产使用当前production gate要求，不把旧缺字段记录写成PASS。
4. 三个开场比较与核心动作成立后，再写可合成文案，按规定Audio Director→Audio→独立音频QA→Editor及最终各项QA推进。重型渲染串行持锁，全文使用同一冻结版本。
5. 先完成EP07局部可审片及必要预览，再推进07全片；08/09逐集接续。不先合成三集旁白或开三个重渲任务，不承诺未经可行性验证的日期。
