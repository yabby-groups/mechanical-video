# EP01 连续动作修订

本修订仅制作 EP01，旧版和 `mechanical-hook-6e21ea58c8729117` 参考保留；不运行整季 worker，不解除 `editorial-hold.json`。

入口：`.venv/bin/python scripts/ep01_continuous/run.py preview`。导演文案、动作、声音与渲染脚本归档在独立内容指纹目录 `series/3d-printer-v2/revisions/EP01/<hash>/renderer/`。脚本变化创建新目录；语音只复用已成功生成的相同 Moon 文本。生成不确定时保留提交标记，禁止自动重复请求。

100 秒动作链：工具头外壳展开、送料齿轮靠近、沿线材下移、退镜交代喷嘴与热床、横向和前后移动、固定热床与龙门上升、整机合壳。源模型不重新生成。外板在开场已经侧移到展示位置，工具头前罩和送料壳连续展开；尾段外板连续归位。所有源几何保持可见标记，出画和遮挡由连续运动产生。

Moon / qwen3-tts-flash 八句旁白按实测时长布置；无语速重定时，无背景音乐。字幕仅在相应音频期间显示，每条单行、不超过 20 字。字幕段内的分配以字符比例估算，不声称逐字对齐。拟音为程序合成，通过实测配音窗口降低音量；不是机器实录。

预览以 270×480、7.5fps 采样完整时间线，封装到 1080×1920/30fps，不能将预览插帧视为正式渲染。正式版实际渲染 3000 帧。预览检查通过后写入带预览 SHA-256 的 `preview-reviewed.json`，再运行 `run.py production`。两阶段均持有共享 render.lock；场景逐采样检查相机、缩放、零件平移和可见集合连续性。正式版检查全部 2999 对相邻帧。旋转与移动为演示，并非机构动力学求解。

每版保留 scene.blend、所有 JPEG 帧、音频、字幕、导演文案、内容哈希、场景检查与媒体验证。技术通过不代表用户对成片观感的认可。

帧缓存仅在 scene.py、motion.py、源场景和模型四个哈希完全一致时复用，并分别保留 preview-frame-cache-provenance.json 和 production-frame-cache-provenance.json。字幕和旁白时序修订只重新封装；不得将不同场景导演版本的帧混合。
