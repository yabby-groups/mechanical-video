| EP03 待研究与局部预览 | 两台电机怎样让喷头走两个方向？ | 打开上部 → 沿两条皮带追踪电机、带轮、固定点和滑架 → 对照组合运动 | 两台电机共同决定 XY；皮带传力、导轨导向。不扩讲 Z 或电机内部 |
| EP04 待深化 | 热床不动，整个龙门怎样升高？ | 单角电机、减速和提升皮带 → 龙门连接 → 四角协作 | 单角提升如何组成整架升降，高度为何要协调；不冒充调平控制或故障仿真 |
| EP05 待深化 | 喷嘴要热，为什么还有两路冷却？ | 打开工具头 → 冷端、热隔离和热区 → 两路风道及目标 | 新增热隔离结构及冷端/成形冷却区别，不重复 EP01 送料；不编造风扇转向、风量或温度数值 |
| EP06 待深化，收尾 | 第一层下面，究竟是谁托着谁？ | 床面与实际支撑展开 → 回接机架 → 间距与铺线截面对照 → 整机回扣 | 支撑、喷嘴间距与附着共同影响第一层；材料截面明确为原理示意，不是实测打印 |

每集遵循“可辨认动作和问题 → 拆开机构 → 新增可见关系 → 动起来验证 → 一个可复述结论”。保持空间、方向和动作连续，不强求一镜到底，不用镜头移动或标签增加代替知识推进。正式片≥90秒、1080×1920编码、30fps、H.264/AAC；另记原生规格，不把上采样称原生高清。字幕单行、每条≤20字符、同时仅一条。不以循环、拉慢语音或重复预告填时长。

## 下一制作对象：EP03

1. Research 对照官方源装配与可靠装配资料，确认两条皮带的完整路线、层位、驱动轮/惰轮及固定点。建立电机转向与滑架位移对应，注明观察方向、引用和推断边界。
2. Visual 核对 occurrence、独立导出及变换，复用修正源。先验证单路输入及两路同向/反向组合；具体符号须根据当前走线确定。现有通用 `travel` 动画只显示位置变化，不证明 CoreXY 正确传动。证据不足时阻断相应内容，不用假走线补画面。
3. Creative Director 比较三个开场并记录选择和每段新增信息，再交 Script。优先 A；只有走线与运动验证通过后进入局部制作。

| 开场 | 可见动作与问题 | 取舍 |
| --- | --- | --- |
| A 优先 | 喷头直线运动，连续打开上部露出两路皮带：谁在拉它？ | 保留整机参照，从结果追到传动原因 |
| B | 单电机输入与双电机配合，对照滑架路径 | 因果直观，但须先证明运动映射及可读性 |
| C | 从驱动带轮沿皮带追到固定点与滑架 | 路线清晰，但须避免没有结果的零件巡游 |

4. Script 按“位置变化 → 两路输入 → 路线与连接 → 组合验证 → 传力/导向区别”准备 Kai 文案和估计时间线。动作验证前不提交配音；合成后根据实测时长定字幕和镜头。
5. 局部 A/B 使用相同片段范围及可比字幕、声音，保持整机方向参照。实际看清路线、固定点和运动关系后按该集预览机制决定整片，不先做三套全片。

生产时 Director 按需派真实 Research、Creative Director、Script、Visual 等子角色，明确独占输出；文档规划阶段不假称已经派工。新增旁白按 Audio Director → Audio → 独立两类音频 QA → Editor → 两类最终混音 QA → Video QA → Audience QA → Director 推进。重型渲染串行持 `render.lock`。

## 推进、验收与执行边界

- 顺序：规划落地 → EP03 源/动作验证与局部预览 → EP03 完整版本及 QA → EP04 → EP05 → EP06。后续选题不构成旧批量队列恢复授权；逐集处理生产与预览范围。
- 连接或形状有疑问先查源，不靠相机掩盖。动作改时点联查拟音、字幕、标签和邻段；全片冻结同一渲染器，不跨版本拼帧。两轮无可测改善停止同策略，每问题最多三轮自动修复，保留计数。
- 完整片检查实际实时节奏、Kai 听感、音画对应与手机字幕；遵循[视频 QA](video-qa.md)、[协作规范](../.codex/agent-workflow.md)及 [AGENTS.md](../AGENTS.md)，完成适用测试、独立 CAD 验证、ffprobe 与全片解码。既有综合/技术≥90、观众≥85、音频技术≥90、音频吸引力≥85及全部门槛不变；缺证据为 null/NEEDS_REVIEW。
