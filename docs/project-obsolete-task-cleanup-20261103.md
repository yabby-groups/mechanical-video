## 分析范围与处理原则

遍历项目文件，包括被 Git 忽略的 `series/`、`artifacts/`、`output/`，以及程序、脚本和测试目录。排除 Git 内部数据、虚拟环境、项目技能和代理配置；这些不是制作临时数据。检查两代系列的作业清单、renderer 快照、编辑版本、当前成片及场景保护集，并扫描保留 Python 源码中对候选目录的完整路径引用。

- 删除没有当前成片、保留场景或 Git 跟踪文件的旧制作任务及旧编辑版本目录；包括任务内已无必要的 renderer 副本、测试几何副本、局部审计和过程日志。删除前逐项记录路径、大小和 SHA256，不另外压缩备份这些废弃任务。
- 全项目删除 Python 字节码、Blender 自动备份、旧演示 review/chapter/preview 图片及可再生成的诊断抽帧。本轮未发现其他 `.tmp`、`.partial`、分析 PCM 候选。
- 保留当前七集成片、批准参考、最终及基线场景、原始 CAD/输入、付费配音与锁定音频、可用源代码、制作/审批/问题记录、队列数据库及现有锁。
- 五个候选目录仍被保留源码直接引用，因此保留。其中 EP07 的 inventory/source 依赖 EP06 旧 full-task 和 EP07 旧 full-task；其他依赖为源审计和局部工具。逐项引用来源记录在机器清单，不因目录名旧而直接删除。
- `artifacts/models` 和 `artifacts/inputs` 是通用流程使用的模型/输入缓存；`output` 中未知用途的有效媒体不因年代或目录名被判定无用。本轮未清理这些源输入，也未声称全项目所有历史目录均已失去用途。
