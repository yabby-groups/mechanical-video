## 二、未来选题的筛选与顺序

先回答：①熟悉的外部动作是什么；②观众可能不知道的关系是什么；③片中哪一个可见变化能证明答案；④看完能复述什么；⑤下一题提供什么不同的新关系。答不清的题先留候选，不能仅因CAD现成入选。

优先级：A为先做源事实与最小动作预检，B为调整表达/验证差异后再排，C为暂缓扩产或复杂度较高。所有题仍须过来源、许可、核心动作与现有制作门槛；A不代表已通过。保留卷尺→拉链→指甲刀→订书机作为近期顺序；后续A题可在每周复盘时替换尚未立项的B/C内容位，替换时登记原因，不自动改ID或重写发布时间。

| 候选题 | 观看动机与改进后的问题 | 必须让观众看见的证据 | 优先级与首要风险 |
|---|---|---|---|
| 卷尺 | 能自己收回，为什么锁住就不回？ | 同一尺带/卷盘的回卷路径，与制动接触解除的对应 | A，当前先完成内部原理；禁止回到已否决尺头题 |
| 拉链 | 小拉头没粘胶，两排牙怎样接在一起？ | 同一对链牙经过拉头前后的导向与接合 | A，限定链牙类型，不虚构变形或普适原理 |
| 指甲刀 | 手柄动一大段，刀口只合一点，为什么？ | 实际结构的支点、传力路径与开合量关系 | A，先核实复合杠杆/弹性片，不能无依据夸大省力倍数 |
| 订书机 | 钉脚穿过纸以后，谁把它折弯？ | 同一枚钉受压、穿纸、接触底座后变形 | A，连续跟踪，不能切走最关键折弯瞬间 |
| 晾衣夹 | 手松开后，夹口的力从哪里来？ | 同一弹簧与夹臂在按下/松开时的关系 | B，原题过于显然；有清楚的新关系才独立成片 |
| 美工刀 | 刀片能推出去，为什么不会自己滑回？ | 实际定位件进入/退出卡位与滑动对应 | B，不拼接不同型号的锁止方式 |
| 喷壶 | 活塞来回动，水为什么只朝喷口走？ | 进/出通路与阀件在两程中的交替状态 | A，限定手扣式泵等具体类型；与皂液泵去重 |
| 回力车 | 往后拉，为什么松手却向前跑？ | 轮轴、储能件和传动在两程中的实际关系 | A，齿轮方向与储能机制必须同源 |
| 修正带 | 两个卷盘越来越一大一小，为什么还能一起走？ | 实际收放、张力调节或滑动关系 | A，先查具体机构，不能默认所有产品同构 |
| 胶带座 | 胶带平时拉不断，为什么靠齿口就容易断？ | 齿口作用位置及可核实的切断过程 | C，偏材料破坏，现有三维机械表达未必合适；避免伪仿真 |
| 棘轮螺丝刀 | 拨一下，哪一侧从传力变成空回？ | 同一输出参照下，换向前后的接触变化 | B，须比棘轮扳手新增换向关系，否则重复 |
| 手摇打蛋器 | 手摇得不快，搅拌头为什么转得更快？ | 同一输入运动与齿轮/输出的对应 | A，明确传动比依据，不靠动画快放冒充传动 |
| 开罐器 | 只转手柄，刀和罐边怎样一直往前走？ | 夹持、进给轮与切割接触的连续关系 | A，先限定结构，核心接触不能被外壳遮住 |
| 自动铅笔 | 松手时，笔芯为什么没有跟着退回？ | 夹持/释放件与同一笔芯在一周期中的状态 | A，不能只做笔芯平移，避免与按动笔转位混淆 |
| 缝纫机 | 针拔出来了，线为什么还留在布里？ | 同一根上线形成线圈并与底线成线的完整路径 | C，柔性线/旋梭可见性预检先行，不只看针上下动 |
| 门锁斜舌 | 门能把锁舌顶回去，关好后为什么挡得住？ | 限定结构的斜面、复位与受力接触差别 | A，只解释结构，不扩展为绕锁操作 |
| 自行车飞轮 | 不踩时轮子还转，为什么脚踏不用跟着转？ | 同一参照下传力与空转路径 | B，与棘轮题重复风险；需不同用途与新证据 |
| 自行车变速器 | 换挡时链条长度没变，多出的部分去哪了？ | 导轮臂变化与链路长度/张紧关系 | A，先回答收链，不扩展一整套变速知识 |
| 雨伞 | 推动一个滑块，整圈伞骨为什么一起展开？ | 同一组连杆铰接从收拢到展开 | B，多杆遮挡、布面与骨架关系先验证 |
| 皂液泵 | 每次松手，下一泵液体怎样补上来？ | 泵腔容积变化与单向阀切换 | B，喷壶若已讲同一因果则后移，不换壳复述 |
| 门把手 | 松开后回正，究竟是哪一处在拉回？ | 把手轴、复位件与锁舌的实际对应 | B，与斜舌题按新增关系决定合并或分开，不预设拆成两片 |
| 电水壶 | 蒸汽到了哪里，开关才会跳开？ | 指定型号中蒸汽路径、温敏件与开关动作 | C，电热/材料变化证据先行，不把所有水壶说成同构 |
| 马桶水箱 | 水位升到这里，谁把进水关掉了？ | 同一浮动件与阀门状态的对应 | A，先限定进水阀类型，勿混入冲水阀 |
| 机械定时器 | 发条一直想回去，为什么能慢慢走？ | 储能、调速与触发响铃的实际路径 | C，若不能清楚讲一个关系则拆小范围，不变成零件目录 |
| 旋转拖把 | 手往下压，为什么拖把变成旋转？ | 同一输入行程与螺旋/传动件、回程关系 | A，限定型号，不预设所有产品同一结构 |
| 手摇卷笔刀 | 刀在转，为什么还能绕着铅笔走？ | 选定刀型的自转/公转及进给对应 | A，先查滚刀型等具体结构，不泛化全部卷笔刀 |
| 打印机搓纸 | 一叠纸挨在一起，为什么一次只送一张？ | 实际送纸与分离件作用的差别 | A，分离机制必须有来源，不把纸张凭空分离 |
| 抽屉滑轨 | 三节轨道怎样接力伸出又不散开？ | 实际滚动/限位/节间运动与完整抽屉的对应 | B，具体滑轨可否支持此描述先核实，不能靠透视假装解释 |

## 三、单集必须填写的制作卡

在既有单集记录中补充以下字段，不另造生产状态系统：

1. **主要目标与次要目标**：例如先让人看懂锁止，次要验证是否形成收藏/关注；不是强制求赞、求藏、求关注。
2. **观看动机**：熟悉动作、未知差异、片中可见答案各一句；观众预设未知时标假设，不声称所有人都误解。
3. **信息兑现**：在实际时间线记录首次动作、首次因果答案、下一条新关系和完整结果的时间码。前3—5秒开始回答是创作目标，不是所有片必须同一切镜模板。
4. **指认与理解**：每个“这里/转一下/卡住/退回”都对应明确可见对象；保持同一参照，先讲差异后给名称。关键接触看不清先查来源/几何，不用快切或标注遮住。
5. **点赞/收藏假设**：具体哪个瞬间有惊讶/审美价值，哪条关系值得再看；没有真实评论/访谈时只写预期，不能填已证实动机。
6. **关注理由**：本集兑现一个完整问题，系列持续提供不同的日常机械因果；统一简洁系列标识，不塞工程细节。结尾若自然承接下一题，给一个真实的新问题，不扣留本集答案、不强制口播关注。
7. **实际证据**：核心动作最小验证、早期组合片段、实际视听QA及明确缺口；静帧/解码不代替实时看懂。
8. **最小实验**：记录本轮主要改变、锁定项、混杂因素、对应指标和失败时查哪里。时长/题材均变化时只能描述，不能称受控A/B。

2026-11-09用户明确核心机制优先：新制作取消统一90秒下限；关键答案、接触/状态切换和完整动作不能为凑时长被漏掉。既有音色/旁白批准、独立QA、源模型许可与修复次数全部沿用。无需为本文件改写已发布片、重新合成音频或批量建队列。
