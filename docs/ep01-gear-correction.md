# EP01 送料齿轮修订

用户发现 `a7fccaff52b0f5e17187` 中齿轮方向有误。复核其归档源装配轴向后，两个夹持齿轮在线材接触处向上运动，而线材标记向下；同轴大齿轮也与驱动齿轮反向。旧成片保留，不作为正确的送料演示。

初版修正任务 `5b846984fff7e103f047` 的接触方向虽已修正，但 7 mm/s 的送料速度使 50 齿大齿轮的齿纹频率超过 30fps 的奈奎斯特频率，画面有倒转错觉风险，故停止正式渲染。当前任务 `b82decd2da0c6a1cb585` 继续使用相同 Voron 模型、Moon 配音、文案与视觉叙事，调整为约 2.5 mm/s 送料和 15fps 全时长预览。角速度从原装配轴向、齿轮中心和假定 1.75 mm 线材直径计算；两侧接触面与线材标记均向下，大齿轮与驱动齿轮共享世界空间角速度。该几何关系是示意性无滑移近似，不是接触仿真或制造精度声明。

新版本入口是 `.venv/bin/python scripts/ep01_gear_corrected/run.py preview` 与 `production`；旧 `ep01_engaging` 入口保留为历史版本，不应用于生成正确送料演示。

预览和正式版各自对每对相邻渲染帧检查齿轮矩阵的实际角速度、接触点速度、同轴关系和线材标记速度；同时保留场景连续性与媒体验证。动力学脚本、导演脚本、配音和内容指纹归档在任务目录。旧输出、参考片和批量队列保留，未重新生成 CAD。

当前任务的 15fps 预览和 30fps 正式版已完成。50 齿齿纹频率约 5.865 Hz，低于预览的 7.5 Hz 奈奎斯特频率并留有余量；图像序列编码时序经 FFmpeg 实测。预览和正式成片的 8 至 9.34 秒齿纹图像相关检查均测得屏幕逆时针转动，方向与计算一致。正式版全部 2999 对帧通过齿轮与线材方向、速度及同轴检查，完整音视频解码通过。旁白、混音和字幕与原成片的 SHA-256 一致。用户观感认可仍待确认。
